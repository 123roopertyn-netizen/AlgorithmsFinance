# Algorithms in Finance — Phase 1

## Project Objective and Specification

This academic project investigates and compares algorithms for membership queries in financial-style datasets. The project will be developed incrementally, with reproducible inputs, identical input/output contracts, test-first implementation, and fair performance and memory evaluation.

The required methods are:

1. Linear Search
2. Binary Search
3. Hash Set Membership

No algorithm implementations, experimental results, or performance claims are included at this stage.

## Reproducibility Requirements

All future work must be reproducible. Synthetic data generation must use documented parameters and controlled random seeds. Algorithms must receive equivalent inputs and follow the same input/output specification. Benchmarking and memory measurements must use documented, fair procedures and must distinguish measured results from interpretation. Dependencies, environment details, and execution instructions will be documented when their development phase is approved.
