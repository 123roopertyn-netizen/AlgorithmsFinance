# Classes 1–2

`class1_profiling_demo.py` generates the three empirical scaling figures used
on the Classes 1–2 slides (`Contains`, `MaxLoss`, `DuplicatePairs`).

From the course root, with this repository linked as `50_code/`:

```bash
python3 50_code/Class1-2/class1_profiling_demo.py
```

Outputs go to `10_overleaf/figures/Class1_Performance/`. Rebuild the slide deck
after a new measurement run.
